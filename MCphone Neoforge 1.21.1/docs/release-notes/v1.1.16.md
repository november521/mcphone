# MCphone v1.1.16

应用市场重做了：图标网格、应用详情页，以及真正会花东西的购买流程。

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装
**可选：** Curios —— 装了多一个手机槽
**可选：** Waystones（传送石碑）—— 装了多一个「传送石」App

**从 1.1.6 升级：** 直接替换 jar。有两处会当场看得出来的变化，往下看「升级须知」。

## 🛒 应用市场

原来是一列纯文字，点一下直接装。现在：

- **图标网格**，排布与主屏一致。名字在图标下面，不再被截断成「便携末影…」
- **点进详情页** —— 大图标、作者、版本、简介、价格
- **一个按钮，四种状态**：购买 / 买不起（灰，写明要什么）/ 下载 / 已安装（灰）
- 翻页骨架已就位。App 还不够一页时不画翻页条，不占地方

## 💰 有两个 App 现在要买

定价思路是**App 卖它替代的那个实物**：

| App | 价格 |
|---|---|
| 便携末影箱 | 1 × 末影箱 |
| 传送石 | 1 × 传送石 |

其余 App 全部免费，详情页直接给「下载」，不多一步点击。

这条规则不需要平衡表，还能自动适配整合包进度——末影箱难做的包里，这个 App 就贵。

**买过就不用再买。** 卸载了再装回来是免费的。

## ℹ️ 关于页

设置里的「关于」原来是往聊天框塞一行字，而且版本号写死成 `v1.0.0`，从第一版起就没跟着改过。

现在是手机里的一页：版本号运行时读，还列出 Curios 与 Waystones 装没装——玩家最常问的两个问题（「手机怎么挂不到腰上」「怎么没有传送石」）九成是这个答案。

## ⚠️ 升级须知

**一、App 安装状态改成按存档隔离**

原来所有存档、所有服务器共用一份 `installed.json`，于是在存档 A 装上的 App，换到存档 B 主屏上还在。现在一档一份。

旧文件会自动迁移给**你升级后第一个进入的存档**，之后改名成 `installed.json.migrated` 留档。所以第一个存档的主屏原封不动，其他存档从默认状态开始。

**二、装着却没买过的付费 App 会从主屏消失**

1.1.6 之前没有购买这回事，所以你的末影箱 App 多半是「装着但没买过」。升级后它会被移到应用商店里，标价 1 × 末影箱。

这不是 bug。不这么做的话会卡死：服务端拦住没买过的请求，而商店只列「没装的 App」，那它就变成用不了也买不到。

**购买按存档记。** 在一个服务器买过，换个服务器要重新买——扣的是真物品，不能拿这边的末影箱换那边的 App。

## 🧩 给附属模组作者

**给自己的 App 定价** —— 新增 `IAppPriceProvider`，走 SPI 注册：

```java
public final class MyAppPrices implements IAppPriceProvider {
    @Override
    public Map<ResourceLocation, ICost> prices() {
        return Map.of(myAppId, ICost.of(Items.REDSTONE, 4));
    }
}
```

文件名 `META-INF/services/com.november.mcphone.api.cost.IAppPriceProvider`。没被报价的 App 就是免费的，不必显式声明。

**这个接口不在 `api.client` 下，实现类里也不许出现客户端类型**：价格两端都要用，客户端画详情页，服务端在扣东西前核对。

**两种代价，用法一样**：

```java
ICost.of(Items.DIAMOND, 3)   // 三颗钻石
ICost.emc(2048)              // 2048 EMC
```

EMC 目前**还没有实现**——`IEmcWallet` 是留好的挂载点，没人接的时候按钮恒灰并写明原因，不会崩也不会白送。将来接 ProjectE 只需写一个钱包实现调 `EmcWallets.set()`。

接口里刻意没有 `getBalance()`：ProjectE 的 EMC 早就超出 `long`，写死类型会在接它时被迫截断，而截断发生在「判断够不够」之前——玩家会看到一个明明够却买不了的价格。所以只问结论，不问数字。

**条件登记** —— 新增 `IPhoneApp.isAvailable()`。你的 App 依赖另一个可选模组时覆盖它，对方没装就不进目录，主屏与商店里都不出现：

```java
@Override
public boolean isAvailable() {
    return ModList.get().isLoaded("someothermod");
}
```

商店里躺着一个点了会报错的东西，比它压根不存在更糟。
