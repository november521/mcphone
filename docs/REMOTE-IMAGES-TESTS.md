# 私人 PNG 与网络回调测试

`phone.image(url,{authorization:''},callback)` 返回 `status`；成功时有本 App 私有的 `src/width/height`，将 src 绑定到 `<image :src="image"/>`。`phone.imageBytes(base64,callback)` 用于已经取得的 PNG 字节，不会再联网。两者共用 PNG 和纹理预算。

图片最多 64 KiB、每边最多 512、最多 262144 像素；PNG 签名、首块 IHDR 及其长度、正整数尺寸在分配像素前检查。包内图片仍保持 128 的原有限制。真实像素只在图片可见时解码，失败显示占位状态。

每 App 最多保留 16 张远程原始图，纹理与包内素材共用 16 张显存预算。相同字节复用句柄。句柄不含 URL 或凭证，不可跨包使用。关 App、卸载、换服、关闭网络许可时释放相应缓存与纹理。

`RemoteImagesTest` 用替身上传器验证尺寸、包隔离和 200 次清理，不能证明真实显卡没有泄漏；下面必须由游戏测试补齐。

1. 默认关闭状态点击私人 fetch/image，确认不联网，返回明确拒绝；分别打开服务器客户端网络许可及玩家对完整包的许可，再请求。
2. 使用测试公共 HTTPS 域名提供 16×16、512×512 的真实 PNG、513×1、超过 64 KiB 的 PNG，以及声明 20000×20000 的小文件；只有前两者显示，超大头在分配像素前拒绝。
3. 返回 HTML/JSON/JPEG、截断 PNG、坏 IHDR 长度和损坏压缩数据；正常占位或错误结果，手机可继续操作。
4. 请求第一次出现 PENDING 后应继续等到 READY/失败。并发同 URL 返回 BUSY；第五个异步请求在本地拒绝，不永久占满四个回调。
5. 结果到达时暂时进行原生吊销检查，检查通过后回调恢复；最终撤销、关闭手机、换服时旧结果丢弃。
6. 使用两份不同测试凭证请求同 URL，结果不串缓存；关闭许可后旧远程 src 不再显示。服务端日志、存档、审计不含 Authorization。
7. 正常图开关 App 200 次，记录客户端内存与显存趋势。卸载后没有继续增长的纹理引用；后台下载完成不得重新创建已关页面的纹理。
8. 请求私有地址、DNS 指向回环/内网、跨主机重定向、混合大小写协议及不在包声明中的域名，均拒绝。使用受控测试地址，避免把真实凭证放入用例。

验收夹具默认声明 example.com，用于许可与非图片拒绝测试。需要成功联网时，按总测试任务说明为你自己的公共测试域名重新生成整套已签名样例，然后部署其中的 feed、ZIP 和 icon.png。
