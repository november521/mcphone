# MCphone v1.2.0

手机里能上网了 —— 这一版的主角是浏览器。

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装
**可选：** Curios —— 装了多一个手机槽
**可选：** Waystones（传送石碑）—— 装了多一个「传送石」App
**可选：** MCEF —— 装了多一个「浏览器」App

**从 1.1.16 升级：** 直接替换 jar。存档、购买记录、App 安装状态都不受影响，没有需要迁移的东西。

---

## 🌐 浏览器

主屏上多一个「浏览器」App。点开是一块占屏幕九成的居中面板，退出回到手机。

**它是唯一一个跳出机身的 App。** 手机屏幕是 120×200 像素，网页塞进去不是「小」，是根本读不了——一行正文占不下十个字。不做成满屏也是刻意的：留一圈边框，你才看得出这是手机里开出来的东西，而不是把游戏切走了。

面板上方一条工具条：后退、前进、刷新，加一个地址栏。右侧那个点是加载指示，亮着说明正在加载。

**地址栏兼搜索框。** 打网址就开网址，打关键词就搜。规则只有三条：

- 带 `://` 的原样打开
- 带空格的一定不是网址，拿去搜
- 剩下的看有没有点——有点当域名补 `https://`，没点当搜索词

中文关键词天然既没有点也没有空格，直接就搜了。

**能用的快捷键**（这些是 MCEF 提供的）：

| 按键 | 作用 |
|---|---|
| `Ctrl` + 滚轮 | 缩放网页 |
| `Ctrl` + `=` / `-` / `0` | 放大 / 缩小 / 复位 |
| `Alt` + `←` / `→` | 后退 / 前进 |
| `Ctrl` + `R` | 刷新 |
| `Esc` | 关掉浏览器（不会传给网页） |

macOS 上用 `⌘` 代替 `Ctrl`。

## 📦 浏览器需要 MCEF

**没装 MCEF 的话这个 App 压根不出现**——主屏和应用商店里都没有它。商店里躺着一个点了会报错的东西，比它不存在更糟。

装了之后，**第一次用还要等 MCEF 下载约 200 MB 的原生库**（java-cef，按平台区分）。这期间打开浏览器会看到「MCEF 还没准备好」，不是坏了，过几分钟再来。下载由 MCEF 自己带界面处理，我们不插手。

MCEF 是 LGPL，本模组是 MIT。我们只链接它的公开 API，一行代码都没抄进来——所以你随时可以把它换成自己改过的版本。

## ⚠️ 已知限制：部分链接点了没反应

**`target="_blank"` 的链接点不动**，搜索结果里这种链接很常见。

这是 MCEF 的缺口，不是你的配置问题：它的 `MCEFClient` 只注册了 Load / ContextMenu / Display / Audio 四个 handler，没有 `CefLifeSpanHandler`，而「网页要开新窗口时怎么办」正在那个接口里。离屏渲染下本来也没有窗口可开，于是点了什么都不发生，也不报错。

我们试过两条路绕开——抢下那个处理器的位置，以及往每个页面注入 JS 改写 `window.open`。两条都是在别人的地基上加自己的拓展，出问题时排查成本远高于收益，所以都撤掉了。这条要等 MCEF 上游补上生命周期回调才好解。

**眼下的办法**：把地址复制进地址栏手动打开。

## 🐛 修掉的

浏览器从第一版起改了十几轮，值得单独说的几条：

- **退出界面后不再漏一个 Chromium 进程。** 原来只有按 `Esc` 关闭才会释放浏览器；断线、退回主菜单、世界卸载、死亡界面弹出这些路径走的是另一条回调，浏览器不关，一个看不见的网页继续在后台放视频、发网络请求，直到你退出游戏。

- **在网页里选中文字往面板外拖再松手，不会再把页面搞废。** 原来那一次松手送不到网页，而浏览器内部的按键状态就此清不掉——此后每一次鼠标移动都被当成「按住键在拖」，满页乱选、点什么都变拖拽，只能关掉重开。

- **`Ctrl` + 滚轮缩放能用了。** 原来修饰键被写死成 0 传给后端，等于把 MCEF 已经做好的缩放锁死了。

- **地址栏不再冻死。** 两个不同的成因：代码写入地址栏时被误判成「玩家在编辑」，以及拖动游戏窗口后编辑标记没跟着清。两种表现一样——地址栏停住不动，点了链接页面明明跳了它还显示旧地址，看着像「跳转没发生」。

- **网页上那层雾去掉了。** 界面背景的暗化被画了两遍，第二遍盖在网页上，只有在网页上才看得出来。

- **导航键调大。** 默认字号在这块大面板上像针尖，刷新那个 ↻ 尤其难点。悬停现在会给个底，看得出是个键。

## 🎨 给资源包作者

浏览器的两块底都走 `PhoneSkin`，贴图优先、纯色兜底，放进资源包即可覆盖：

| 元素 | 路径 |
|---|---|
| 面板底 | `assets/mcphone/textures/gui/browser_panel.png` |
| 工具条底 | `assets/mcphone/textures/gui/browser_bar.png` |
| App 图标 | `assets/mcphone/textures/gui/app_icon_browser.png`（20×20） |

面板底会被整张拉伸，而且绝大部分会被网页盖住，纯色就够。现在内置的 App 图标是代码生成的占位地球，画一张真的覆盖掉即可。

## 🧩 给附属模组作者

浏览器后端是可替换的。`com.november.mcphone.client.browser` 下：

- `IBrowser` —— 一个已经打开的浏览器。签名里**一个 MCEF / JCEF 类型都没有**，画面以 GL 纹理 id 交出来
- `IBrowserBackend` —— 谁来提供浏览器，以及「现在能不能用」
- `BrowserBackends.set(backend)` —— 挂载点，先到先得

想换成别的后端（自己的 CEF 封装、别的渲染方案），在 MCphone 客户端启动装上默认后端之前调 `BrowserBackends.set()` 即可。已经有人接管时再 set 会被拒绝并告警，不会静默顶掉。

这几个接口在 `client` 包下，不在 `api` 里：`IBrowser` 要返回 GL 纹理 id，本来就只在客户端有意义。服务端一个字节都不会碰到 MCEF。
