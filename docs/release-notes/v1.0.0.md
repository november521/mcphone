# MCphone v1.0.0 —— 首个正式版本

把一部能用的智能手机塞进 Minecraft：拍照、翻相册、换壁纸、听歌、装 App，还能给自己的手机起个名。

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装

---

## 怎么拿到手机

工作台合成，一次一部：

```
玻璃   玻璃   玻璃
红染料 黄染料 蓝染料
铁锭   红石   铁锭
```

拿在手上右键开机。点机身外的区域关机。

---

## 这一版有什么

### 📷 相机
进入相机模式后屏幕出现取景框，**V** 拍照、**X** 退出（两个键都能在原版「选项 → 按键设置 → MCphone」里改）。截图分帧进行，不会卡住渲染。照片存进游戏目录的 `screenshots/`。

### 🖼 相册
缩略图网格 + 分页浏览，点开是大图，左右可以逐张切换，也能直接删除（需再点一次确认）。缩略图按需生成并缓存，翻页不会反复解码整张 PNG。

### 🎨 壁纸
把**任意尺寸**的 PNG 丢进 `config/mcphone/wallpapers/`，在「设置 → 更换壁纸」里挑，随时可恢复默认。壁纸选择由服务端保存并同步，多人游戏里每位玩家的壁纸都跟着自己走。

### 🎵 音乐
播放原版唱片音乐（走 1.21 的 `JukeboxSong` 注册表），也能播放你自己放进 `config/mcphone/music/` 的 WAV 文件。OGG 建议通过资源包加载。

### 🏪 应用商店 & App 管理器
主屏的 App 可以从商店安装、在管理器里卸载，安装状态会持久化保存。系统 App 在列表中标灰、不可卸载。

### ⚙️ 设备名称
在「设置 → 设备名称」里给这一部手机起名，起过名的手机在物品栏里就显示这个名字。最长 24 个字符，服务端会做校验与截断（表情符号不会被劈成半个）。留空保存即恢复默认。回车＝保存。

> Minecraft 的 GUI 不支持输入法，中文名请用 **Ctrl+V** 粘贴进输入框。铁砧改名的优先级更高，会盖过设备名。

### 🌏 多语言
简体中文与英文全量支持，界面上没有硬编码文本。

## 给附属模组作者

MCphone 的 App 系统是开放的，通过 SPI 自动发现——你的模组不需要被 MCphone 感知，也能往手机里装 App：

- `com.november.mcphone.api.IPhoneApp` —— 实现它并在 `META-INF/services/` 中注册，App 会自动出现
- `com.november.mcphone.api.store.IAppSource` + `AppInfo` —— 自定义应用商店来源

内建 App 走的是同一套注册机制，没有走后门。
