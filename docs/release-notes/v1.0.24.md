# MCphone v1.0.24

联系人有脸了，消息也不会再错过。

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装

---

## 🧑 玩家头像

会话列表、加联系人、会话标题三处都会显示对方的头像，取的就是**按 Tab 看到的那一份**，包括帽子层。好友在下界、在几千格外都照样显示——玩家列表本来就是全服共享的。

在线状态点挪到了头像右下角，不再单独占一列，省下的宽度还给名字。

**好友离线时显示的是默认皮肤**（Steve 或 Alex）。离线玩家压根不在玩家列表里，客户端手上只剩一个 UUID——这是数据源的边界，不是漏做。

---

## 🔔 消息提醒

**身上带着手机时**收到消息，屏幕右上角弹一条通知：头像、发信人、消息内容。

- **同一个人连发会合并成一条**并显示条数，不会把通知区堆满。
- **正看着这个会话时不弹** —— 消息已经在眼前了。看别的会话、或停在手机的其他界面，照常提醒。
- **手机不在身上不弹**，但消息照常收着，下次拿起手机就能看到，一条都不会丢。

用的是原版通知机制而不是往聊天框里发消息：聊天框容易被刷屏淹没，也会一直占着聊天记录。
