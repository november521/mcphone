# MCphone v1.11.0

本次更新完善美西螈聊天界面，加入消息文字拖选、右键复制与个人删除，以及输入框右键粘贴。暂时隐藏尚未开放的保险箱和我的签名密钥设置入口。

## 运行环境与升级

- Minecraft 1.20.1：Forge 47.4.0 或更高，Java 17。
- Minecraft 1.21.1：NeoForge 21.1.200 或更高，Java 21。
- Minecraft 1.21.1：Fabric Loader 0.15.0 或更高、Fabric API，Java 21。
- 客户端与服务端均需安装对应加载器的版本。

聊天网络协议已更新，客户端与服务端需要一起升级，旧版 MCphone 不能与本版混用。关闭游戏后替换原来的核心 JAR，同一实例保留一份 MCphone，并保留附属模组。

升级前请备份世界。个人删除记录会随世界保存；旧版本不识别这些记录，降级可能重新显示已删除消息，需要降级时请恢复升级前的世界备份。

## 美西螈聊天

- 调整会话列表、头像、输入栏与按钮间距，采用紧凑字号和半透明面板。
- 接收气泡使用提亮的灰蓝色，发送气泡保留莓紫色；气泡与输入框增加浅色细描边和轻微阴影。
- 支持鼠标拖选消息正文并复制，保留原文和手动换行，不把自动折行转换成换行。
- 文字消息右键显示带图标的「复制」「删除」；已有选区时复制选中文字，图片消息提供删除。
- 删除只影响自己的记录，对方仍能查看原消息及图片；自己的删除标记随世界持久保存。
- 输入框右键提供带图标的「粘贴」，支持替换已有选区，粘贴不会直接发送消息。
- 菜单和图片查看器打开时阻断下层输入，避免隐藏草稿被 Enter 发送。
- 修复切换会话后的图片请求范围，以及异步上传跨连接、跨任务完成的问题。
- 离线联系人可继续使用本次客户端运行期间已经加载的皮肤头像，尚不包含重启后的持久化头像恢复。
- 拆分消息排版、绘制、滚动、输入、图片查看和右键菜单组件，完善相关回归校验。

## 手机界面与设置

- 状态栏调整为左侧时间、右侧信号与电池图标。
- 本地目录入口改用图标，音乐 App 增加打开本地音乐目录的入口。
- 暂时隐藏设置中的「保险箱」「我的签名密钥」，保留已有实现和数据，待开放后恢复入口。

本版仍支持上述三个现有平台；26.1、26.2 的适配将在后续开发中进行。
