# 脚本化 App 平台开发收尾

本轮补齐施工方案中允许开放的脚本执行、商店、更新、存储和原生管理功能。三个目标共用实现：Forge 1.20.1、NeoForge 1.21.1、Fabric 1.21.1。测试构建沿用当前仓库版本，正式版本由发布流程决定。

## 功能

- 前端具名函数、真实异步回调、4096 字符输入、客户端保险箱、私人 HTTPS 和 PNG 图片。
- 签名内源商店、独立大文件分块通道、版本见证、作者更新与吊销、原生换作者和手动降级确认。
- 持久守卫、原生礼包、完整物品收件箱、宿主物品引用、物品托管、货币脚本归属及结算日志。
- 受控 HTTPS、命令模板、真实只读资源适配器、持久通知及默认关闭的只读后台。
- 原生权限管理、完整差异确认、配置事务和文件重载、配额与占用、有限审计导出、本人普通 KV 清理。
- 修正旧 1.20.1 测试数据包的物品标签目录；样例检查覆盖版本目录改名，避免许可标签被游戏静默忽略。
- 修复原生管理 UUID 内容行无法聚焦、编辑状态不明显及审批输入缺少键盘捕获的问题；标签和内容行均可编辑，增加光标与输入提示、全选替换和方向键操作。

服务端脚本默认关闭；开启与敏感管理同时要求相应 UUID 角色和 OP 权限。发生无法确认的物品或金额操作时保留 UNKNOWN，核对后人工处理，不自动重试。

## 验证与边界

完整构建执行仓库断言测试和架构检查。另提供经真实解析器、编译器及双签名验证的测试包，以及 T01–T43、A1–A11、R1–R7 游戏测试任务。游戏内、外部提供者和故障窗口验收由用户执行，自动化通过不代表游戏验收完成。

`cost` 按方案明确拒绝。B 档预留接口、未开放能力与需要外部提供者的功能边界见 [完成矩阵](../COMPLETION-MATRIX.md)。
