# MCphone v1.8.0

**手机里多了一个「阅读」App —— 整合包里几十本教程书，收进一个书架，打字就能找** 顺带修掉一个能让整块屏幕不显示的渲染 bug，音乐、唱片仓、相册也各修了一批。

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装
**可选：** Curios —— 装了多一个手机槽
**可选：** Waystones（传送石碑）—— 装了多一个「传送石」App
**可选：** MCEF —— 装了多一个「浏览器」App
**可选：** NetMusic（网络音乐机）—— 装了唱片仓还收它刻的 CD
**可选：** Patchouli（教程手册）—— **本版新增**，装了多一个「阅读」App
**可选：** Integrated Dynamics —— 装了**不**多任何东西，只让崩溃报告指认对人

**从 1.7.0 升级：** 直接替换 jar。存档、好友关系、聊天记录、购买记录、App 安装状态、主屏图标位置、手机里的唱片全部原样保留 —— 这一版没动任何存储格式。服务端换不换都行（改动全在客户端），但建议一起换，省得版本对不上。

## 📖 「阅读」—— 整合包里的教程书全在这儿

**需要 [Patchouli](https://modrinth.com/mod/patchouli)。** 没装则这个 App 不会出现在主屏与商店里。

几百个模组的整合包里，教程书有几十本，每一本都是一个物品。想查点什么就得先在仓库里翻出那本书，翻完还得放回去；出门在外想起要看，书多半不在身上。这个 App 把它们全列在一页里：

- 一行两句话：**书名**，以及**它是哪个模组的**。第二行写模组名而不是副标题，是因为找书的思路几乎总是"某某模组那本书"——很多书名起得花，光看名字认不出是谁的
- 行首那张小图就是那本书自己的样子，玩家在仓库里见过它，一眼能认
- **没有物品的书也在**：有些模组的书是 `no_book` 的，游戏里根本没有对应物品，只能用命令打开——它们在这里一样列着，点了就能看

**翻书仍然是 Patchouli 在翻。** 点开一本书，接管屏幕的是它自己的界面，进度、已读标记、条目锁定全都对得上，和你在背包里右键那本书一模一样。我们只提供目录——它的书界面是 272×180，手机屏幕只有 120×200，放不下；而自己重画就要把它几十种页面类型重新实现一遍，它一改版就断。

**合上书之后**按 ESC 回到游戏（ESC 本来就该干这个），下次开机手机直接停在书架上，不用再从主屏点一遍。

## 🔍 进这一页直接打字

书架顶上那条是搜索框，**进来它就已经拿着焦点了**，想找哪本直接敲，不用先点一下。

**书名、模组名、模组 id 三样都能搜。** 中文客户端里一本书的名字是中文、出处是英文很常见，只搜一个字段就会出现"我明明记得这个模组叫什么，却搜不到它的书"。多个词用空格分开是「与」的关系，各自可以命中不同字段（`ars 笔记`）。

结果按分数排：**书名命中排在模组名命中前面**，前缀命中排在中间命中前面——打「新生」的人要的是那本书，不是"出自某个名字里带新生的模组"的一堆书。右上角的数字在搜的时候变成「命中/总数」。

这一页会吃掉所有按键（包括背包键），和记事本、改设备名那几页一样：打拼音必然按到 `e`，不吃掉就成了开背包。`ESC` 照旧是直接关机。

暂时没有拼音搜索（`xsmy` → 新生魔艺），那要一张拼音表。

## 🧩 个别模组要特殊照顾

有些模组把自己的手册整个换掉了，Patchouli 里只剩一本没人维护的旧书。这类走一层「书籍特例」：能把某本书从架子上拿掉、改写它的显示、接管「点开之后打开什么」、或者指定用哪张图当图标。

目前只有一条——**新生魔艺（Ars Nouveau）**。它 5.x 起换成了自研的文档系统，右键笔记本打开的是那个界面，但 jar 里仍留着一本 Patchouli 书（条目只有英文，内容停在换系统那天）。所以在手机里点它的笔记本，打开的是**它自己的文档界面**，图标也用回它换 3D 模型之前那张平面小图。

## ⚠️ 一个能让手机整块屏幕不显示的 bug

物品模型的 parent 写成 `builtin/entity` 时，画它的是**那个模组自己的渲染器**。GeckoLib 那类渲染器在 GUI 里会 `endBatch` 掉共享缓冲、`enableDepthTest` 开完不还原，模型走 `entityTranslucent` 画在 GUI 的 z=150 上**会写深度**——而手机后面画的行、导航栏、外壳都在 z≈0，GUI 的深度测试是 LEQUAL，于是全被判在它后面，直接不画。

症状是"手机开着，屏幕上什么都没有"，看起来像整个界面坏了，真凶只是列表里某一行的一张小图标。现在带自定义渲染器的物品一律不画，退回通用书图。

## 🖼 相册：删除挪到右上角，序号挪回正中

单张查看原先是**序号占着右上角、删除夹在底部两个翻页箭头中间**。翻照片是要连点箭头的，而删除是这一页唯一不可撤销的动作——把它摆在两个连点目标的正中间，等于专挑最容易点错的位置放最不该点错的键。

现在底部那一行是 `◁ 3/47 ▷`，与网格页的翻页条一模一样；删除去了右上角，仍然要点两次。

顺带：确认文案原先居中画会盖到两边箭头上，英文那句直接画出屏幕外，现在右对齐并留缝。返回键的对齐、删除键的贴图接口（`gallery/delete.png`）也是这一版加的。

## 🎵 音乐与唱片仓

- **乱音、"暂停了还响"的真正根因**：我们霸占了 OpenAL 的当前上下文没还回去。原版的音效系统与我们抢同一个上下文，谁后调谁生效
- **停止播放的包发给"当初听见的人"**，不再是"此刻在附近的人"——走远了再停，原地那些人的声音以前会一直响下去
- **进度条真的会走了**：时长在解码时就算出来，不再等整首放完才知道多长
- **换碟从三步变一步**：仓里有唱片时也能直接开背包界面
- shift 点击把正在放的唱片搬出仓，声音会停；取出唱片同样要求手机在身上；曲库滚轮到底就是到底，不再空滚

## 📱 手机本体

- **任何界面点机身外都能收起手机**，不必先退回主屏
- **重开手机停在上次那一页**（目前只有美西螈与阅读享受这个待遇，别的一律回主屏——低频页面续开反而碍事）
- **主屏图标右上角画未读角标**，美西螈先用上，附属模组实现 `getBadgeCount()` 即可
- 没壁纸时的底色换成夜空藏蓝

## 🎨 做过资源包的看这里

**导航栏底与三个虚拟键现在是贴图**：`phone/nav_bar.png`、`phone/nav_back.png`、`phone/nav_home.png`、`phone/nav_tasks.png`。不放贴图仍然画原来的字符与纯色，不受影响。

**半透明像素终于是半透明的了。** 1.7.40 之前，贴图里 alpha 介于 0 与 255 之间的像素会被当成不透明画出来——抗锯齿边缘发硬、整块半透明的底变成实心。根因是原版 `GuiGraphics.blit(ResourceLocation, …)` 这条路从头到尾没碰过混合状态，而 GUI 里每画完一次 `fill` 或一行字，混合都会被关掉。

自带的 12 张 App 图标里有 7 张带抗锯齿，它们一直在画硬边。这一版修好之后，**你资源包里那些带羽化边缘的图会跟着一起变对**，不用改任何东西。

本版新增两个换肤位：`reader/book.png`（书架上那本兜底的书，16×16）、`reader/search_bar.png`（搜索栏的底，112×12）。

## 给服主

这一版没有新增配置项，也没动任何存储格式与网络协议。「阅读」App 是纯客户端的：书目从客户端自己的模组文件读，翻书由 Patchouli 在客户端打开，服务端一个包都不会多收。音乐那几条修复里，"停止播放发给谁"改的是服务端的收件人计算，行为更对，协议没变。
