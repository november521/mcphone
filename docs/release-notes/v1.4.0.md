# MCphone v1.4.0

主屏终于能像真手机那样用了 —— **图标能拖着换位置，装不下就翻页**。后半程是一轮全项目体检，修掉的东西玩家大多看不见，但服主看得见。

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装
**可选：** Curios —— 装了多一个手机槽
**可选：** Waystones（传送石碑）—— 装了多一个「传送石」App
**可选：** MCEF —— 装了多一个「浏览器」App

**从 1.3.7 升级：** 直接替换 jar。**存档、好友关系、聊天记录、购买记录、App 安装状态全部原样保留**，退回旧版也照读。

## 📱 主屏：能拖，能翻页

从前主屏是一块固定的板子：App 按加载顺序排好，你摆不动它，装够二十个之后第二十一个就没地方去了。

现在：

- **按住图标拖着走**，松手落定。中间的图标依次前移，跟真手机一样 —— 不是跟落点那个对调。对调会让另一个图标莫名其妙跳到你手指原来的位置上。
- **一页装满 20 个（4×5）就自动翻页**，底部有页码点。翻页有三条路：滚轮、在空白处横着划一下、点页码点直接跳。
- **拖着图标停在屏幕左右边上不动**，那条边会由浅到深亮起来，停够 0.4 秒自动翻到下一页 —— 手不用松，直接把 App 搬到别的页去。

最后这条不是锦上添花。没有它的话分页只做了一半：拖动只能落在**当前这一页**的格子里，而翻页要么得松手（松手就落定了），要么得腾出另一只手滚滚轮。跨页搬不了，分页就是半截功能。

停留 0.4 秒而不是碰到就翻，也是有原因的：拖去最右那一列的路上必然会扫过右边条，一碰就翻的话，最后一格永远放不进去。

**摆好的顺序跟着存档走**，下次进来还是你摆的样子。

## 🔔 加好友不再是"点了没反应"

**这是这一版对玩家最实在的修复。**

从前加不上好友时，界面上只有一种表现：按钮闪一下，还是「+ 添加」。而它背后可能是四种完全不同的情况 —— 我的好友满了、对方的好友满了、对方待处理的申请太多了、这个人服务端根本没见过。玩家分不出来，只会反复点，然后来报「加好友是坏的」。

现在每一种都会在动作栏上说一句话。

还有一个更隐蔽的：**同意好友申请时如果你的好友已经满了，那条申请会被吃掉** —— 申请消失，好友没加上，而发起人那边的「已申请」会悄悄变回「+ 添加」，他根本不知道自己被同意过一次又被退了回去。现在满员时申请原样留着，你腾出位置再回来点，它还在。

## 🖥️ 给服主的：两处服务端负担

**一、拉会话列表不再扫全服。**

好友关系从前存成一串 `"玩家A|玩家B"`，问「某人有哪些好友」只能遍历全服每一条关系逐个解析。而客户端每 3 秒拉一次会话列表都要走这一遍 —— 100 个玩家各 50 个好友，就是每人每次轮询扫 2500 条。现在换成邻接表，一次哈希查找。

**存档格式一个字节都没变。** 老存档照读，新存档拿回 1.3.7 也照读。

**二、服务端不再听凭客户端自觉。**

界面自己约好了 3 秒拉一次，但那是客户端代码里的一个常量，改一行重新编译就没了。改过的客户端可以每 tick 发一个请求，也就是每秒 20 次。手机从 v1.3.0 起是开放给别人用的，一个人就能让服务端主线程忙起来，不需要什么高明的手段。

现在七类「来要数据」的请求各有 500 毫秒的最小间隔。**做事情的包不限流** —— 发消息、加好友、存笔记这些是按一下才有一次的动作，而且把玩家刚打的一条消息静默丢掉，比慢一点糟得多。

**三、README 补上了 Integrated Dynamics 那一段。** 装了 ID 时 MCphone 会在方块注册末尾做一件事，此前三处文档一处都没提。它不给你加任何功能，也救不回起不来的服务器 —— 它让崩溃报告指认真凶，而不是甩锅给 ID。

## 🎨 给资源包作者：三个新贴图口子，一处文档更正

主屏分页带来三个可换肤元素，都是纯色兜底，不放贴图功能完全正常：

| 路径（相对 `assets/mcphone/textures/`） | 建议尺寸 | 用途 |
|---|---|---|
| `phone/page_dot.png` | 3×3 | 页码点，不是当前页的那些 |
| `phone/page_dot_active.png` | 3×3 | 页码点，当前页 |
| `phone/page_edge.png` | 10×176 | 拖着图标停在边上时那条提示竖条 |

另加 1.3.9 的 `phone/drop_slot.png`（20×20，拖动时"松手落这儿"的空槽提示）。

**一处文档更正**：`PhoneTheme` 文件开头那张贴图清单是 1.2.7 之前的老路径，照它做出来的贴图**一张都不会加载**，而且不报错，表现只是"我放了图，改了没反应"。那张表已经删掉，改为指向真正的契约。**README 的换肤表一直是对的**，按 README 做的资源包不受任何影响。

## 🔧 底下的事

- **界面颜色统一了。** 全项目 113 处写死的颜色收进 `PhoneTheme`，现在改配色只需要改一个文件。此前同一个"确认绿"分散在发送、保存、添加、打印、改设备名五个文件里各写一遍。改动前后逐个核对了 222 个颜色值，**没有任何一处颜色发生变化**。
- **十三份复制粘贴的小工具合并了** —— 矩形命中判定五份（三个不同的名字）、文字截断五份、时间显示两份。顺带修好一处不一致：商店详情页那份截断和其余五处的算法不一样，中文字体下省略号会被挤出可用宽度。
- **主屏的 App 计数不再每帧建两个列表。** 从前为了拿一个整数要先造一个列表再拷一份，而这条路一帧走四五次。
- 删掉了 1.3.10 加的调试用占位 App 和 `/mcphone debugapps` 命令 —— 那是为了测分页造的脚手架，测完了不该留在正式版里被误触。
