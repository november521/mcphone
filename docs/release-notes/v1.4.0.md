# MCphone v1.4.0

三件事：**多了时钟和天气两个 App**、**字能换颜色了**、**主屏终于能像真手机那样用**（图标拖着换位置，装不下就翻页）。中间夹着一轮全项目体检，修掉的东西玩家大多看不见，但服主看得见。

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装
**可选：** Curios —— 装了多一个手机槽
**可选：** Waystones（传送石碑）—— 装了多一个「传送石」App
**可选：** MCEF —— 装了多一个「浏览器」App
**可选：** Integrated Dynamics —— 装了**不**多任何东西，只让崩溃报告指认对人，见下方「给服主的」

**从 1.3.7 升级：** 直接替换 jar。**存档、好友关系、聊天记录、购买记录、App 安装状态全部原样保留**，退回旧版也照读。

## ⏰ 时钟：在下界也知道地面上几点了

新 App，免费，装上就在。它回答四个问题：

- **游戏里几点、第几天** —— 和 `/time query day` 是同一个数
- **现实里几点**
- **还有多久天黑**（或者天亮）
- **玩了多久** —— 本次坐下到现在，以及这个存档一共陪了你多久

「存档一共多久」取的是原版「统计 → 游戏时长」那个数，所以你按 Esc 看到的和手机里看到的**是同一个**。另一条路是从装上这个模组那天起自己算，那个方案听着简单，但一个玩了 300 小时的老存档装上手机第二天会显示「12 小时」——那比不显示更糟。

**在下界和末地照常走。** 原版时钟在下界乱转是刻意的设计，但 `dayTime` 在那儿照常同步，所以算出来的是**地表的真实时间**。挖矿的人最想知道的就是「我上去会不会天黑」，原版偏偏不给。

还有一行**说给屏幕前那个人听的话**，按情境挑，不是随机箴言：你刚坐下它说「欢迎回来」，你坐了三小时它就知道你坐了三小时；凌晨两点打开它说「夜深了，早点休息」——按**现实时间**问好，不按游戏时间，因为关怀的对象是你，不是你的角色。

分寸上只陈述不说教：说「已经玩了三个多小时了」，不说「你该休息了」。前者你会在心里接一句「是啊」，后者你会把它关掉。

## 🌦️ 天气：不只是「在下雨」

新 App，免费，装上就在。它说现在是什么天，以及**这种天适合去做什么**。

关键在第一句不是 `isRaining()` 就完了。Minecraft 的天气是全世界一个开关，但落下来的东西按**当地生物群系**算，于是同一个「正在下雨」在三个地方是三种天：

| 你站在哪 | 实际落下来的 | 从前会说 | 现在会说 |
|---|---|---|---|
| 平原 | 雨 | 雨 | 雨 |
| 雪山 | 雪 | 雨 | **雪** |
| 沙漠 | 什么都不落，但天光照样暗 | 雨 | **阴** |
| 下界 / 末地 | 没有天气这回事 | 晴 | **无天气** |

雷雨单独算一种：天光暗得像夜里，地表照样刷怪，但**闪电劈中苦力怕会把它变成高压的**——想抓就是现在。这类"这种天该干嘛"的话每种天各有一句，晴天还分白天夜里（白天说僵尸骷髅会烧起来，夜里说地表开始刷怪了）。

页面正中有一张随天变的 32×32 大图标。

## 🖌️ 字体颜色：六个预设，白配深壁纸，黑配浅壁纸

「设置 → 字体颜色」，六个预设：**白色**（默认）、**黑色**、琥珀、天青、薄荷、樱粉。选中即生效，不用重启。

这是给用了浅色壁纸的人准备的——壁纸浅、字也浅，就什么都看不清了。

**它是客户端设置**，存在你自己的 `config/mcphone-client.toml`，不同步给服务端，换服务器不会变，和资源包一个性质。也可以从模组列表的「配置」按钮进去改（那个按钮此前点进去是空的，因为一直没有任何配置注册给它）。

**只有画在壁纸上的字跟着变。** 导航栏 ◀●■、通知、聊天气泡、商店按钮上的字不跟随——那些底是手机自带的深色构件，玩家换不了；字跟着一起变的话，字和底会往同一个方向走，导航按钮直接消失，而且不报错，只是"点不着了"。

选了黑色时，危险红、确认绿这些**也会换成深色版**，否则浅底上一行浅绿的「发送」等于没写。

**默认那一档与从前逐字节相同。** 不去动这个设置的话，界面和 1.3.7 一模一样——这不是"看起来一样"，是六个预设的算法在白色那一档上算出来的数值与旧常量完全相等，落地时逐个核对过。

## 📱 主屏：能拖，能翻页

从前主屏是一块固定的板子：App 按加载顺序排好，你摆不动它，装够二十个之后第二十一个就没地方去了。

现在：

- **按住图标拖着走**，松手落定。中间的图标依次前移，跟真手机一样 —— 不是跟落点那个对调。对调会让另一个图标莫名其妙跳到你手指原来的位置上。
- **一页装满 20 个（4×5）就自动翻页**，底部有页码点。翻页有三条路：滚轮、在空白处横着划一下、点页码点直接跳。
- **拖着图标停在屏幕左右边上不动**，那条边会由浅到深亮起来，停够 0.4 秒自动翻到下一页 —— 手不用松，直接把 App 搬到别的页去。

最后这条不是锦上添花。没有它的话分页只做了一半：拖动只能落在**当前这一页**的格子里，而翻页要么得松手（松手就落定了），要么得腾出另一只手滚滚轮。跨页搬不了，分页就是半截功能。

停留 0.4 秒而不是碰到就翻，也是有原因的：拖去最右那一列的路上必然会扫过右边条，一碰就翻的话，最后一格永远放不进去。

**摆好的顺序跟着存档走**，下次进来还是你摆的样子。

## 🔔 加好友不再是"点了没反应"

**这是这一版对玩家最实在的修复。**

从前加不上好友时，界面上只有一种表现：按钮闪一下，还是「+ 添加」。而它背后可能是四种完全不同的情况 —— 我的好友满了、对方的好友满了、对方待处理的申请太多了、这个人服务端根本没见过。玩家分不出来，只会反复点，然后来报「加好友是坏的」。

现在每一种都会在动作栏上说一句话。

还有一个更隐蔽的：**同意好友申请时如果你的好友已经满了，那条申请会被吃掉** —— 申请消失，好友没加上，而发起人那边的「已申请」会悄悄变回「+ 添加」，他根本不知道自己被同意过一次又被退了回去。现在满员时申请原样留着，你腾出位置再回来点，它还在。

## 🖥️ 给服主的

先说这一版的三个新东西给你添了多少事。

**天气、字体颜色：零。** 天气本来就在客户端手上（抬头看天和手机看的是同一份数据），字体颜色是客户端配置，不上网。

**时钟：一个原版包，有节流。** 「本次玩了多久」纯客户端算，不问你要。「这个存档一共多久」要不到——客户端的统计表是每次连接新建的空表，服务端不会主动推。所以我们发 `ServerboundClientCommandPacket(REQUEST_STATS)`，**就是玩家按 Esc 打开原版「统计」界面时发的那一个**，不是我们自定义的协议，你的服务端不需要装任何东西。

服务端收到它会把该玩家的全部统计序列化发回来，一个老玩家几 KB。所以卡了三道：**进世界时一次、打开时钟那一页时一次、之后最快 10 秒一次**。存档总时长按"几小时几分"显示，10 秒的陈旧在界面上根本看不出来。

不节流的话，时钟页开着就是每帧几 KB —— 那正是下面第二条刚修掉的那种事，只不过加害者会是我们自己。

下面两条是真的减负。

**一、拉会话列表不再扫全服。**

好友关系从前存成一串 `"玩家A|玩家B"`，问「某人有哪些好友」只能遍历全服每一条关系逐个解析。而客户端每 3 秒拉一次会话列表都要走这一遍 —— 100 个玩家各 50 个好友，就是每人每次轮询扫 2500 条。现在换成邻接表，一次哈希查找。

**存档格式一个字节都没变。** 老存档照读，新存档拿回 1.3.7 也照读。

**二、服务端不再听凭客户端自觉。**

界面自己约好了 3 秒拉一次，但那是客户端代码里的一个常量，改一行重新编译就没了。改过的客户端可以每 tick 发一个请求，也就是每秒 20 次。手机从 v1.3.0 起是开放给别人用的，一个人就能让服务端主线程忙起来，不需要什么高明的手段。

现在七类「来要数据」的请求各有 500 毫秒的最小间隔。**做事情的包不限流** —— 发消息、加好友、存笔记这些是按一下才有一次的动作，而且把玩家刚打的一条消息静默丢掉，比慢一点糟得多。

**另外，README 补上了 Integrated Dynamics 那一段。** 装了 ID 时 MCphone 会在方块注册末尾做一件事，此前三处文档一处都没提。它不给你加任何功能，也救不回起不来的服务器 —— 它让崩溃报告指认真凶，而不是甩锅给 ID。

## 🎨 给资源包作者：新贴图位、一个生成器、一处文档更正

主屏分页带来三个可换肤元素，都是纯色兜底，不放贴图功能完全正常：

| 路径（相对 `assets/mcphone/textures/`） | 建议尺寸 | 用途 |
|---|---|---|
| `phone/page_dot.png` | 3×3 | 页码点，不是当前页的那些 |
| `phone/page_dot_active.png` | 3×3 | 页码点，当前页 |
| `phone/page_edge.png` | 10×176 | 拖着图标停在边上时那条提示竖条 |

另加 1.3.9 的 `phone/drop_slot.png`（20×20，拖动时"松手落这儿"的空槽提示）。

**两个新 App 图标**：`app/clock.png` 与 `app/weather.png`，20×20，和其余十个一个规格。README 里那句「内建的十个」也一并改成十二个，并把文件名全列了出来——写数字就要记得改数字，列文件名的话谁加了 App 一眼看得出这里少一个。

**天气页那张大图标**是另一回事：`weather/` 下六张 32×32（`clear` / `rain` / `snow` / `thunder` / `dry` / `none`），**不走换肤那套、没有兜底色**，因为模组自带全套，资源包只是覆盖。要换就六张一起换，只换一两张会画风打架。

**别再照着文档抄清单了，让它自己生成**：

```
python3 docs/make_texture_manifest.py
```

扫出这个模组认得的每一个贴图位，出一张 HTML：路径、建议尺寸、用途、现有的图长什么样（内嵌 PNG，按整数倍放大，透明处有棋盘格）、以及缺图时退回哪个兜底色。

不在文档里存一份写好的清单，是因为那种清单必然过期——**下面这一条就是活例子**。

**一处文档更正**：`PhoneTheme` 文件开头那张贴图清单是 1.2.7 之前的老路径，照它做出来的贴图**一张都不会加载**，而且不报错，表现只是"我放了图，改了没反应"。那张表已经删掉，改为指向真正的契约。**README 的换肤表一直是对的**，按 README 做的资源包不受任何影响。

## 🔧 底下的事

- **界面颜色统一了。** 全项目 113 处写死的颜色收进 `PhoneTheme`，现在改配色只需要改一个文件。此前同一个"确认绿"分散在发送、保存、添加、打印、改设备名五个文件里各写一遍。改动前后逐个核对了 222 个颜色值，**没有任何一处颜色发生变化**。
- **十三份复制粘贴的小工具合并了** —— 矩形命中判定五份（三个不同的名字）、文字截断五份、时间显示两份。顺带修好一处不一致：商店详情页那份截断和其余五处的算法不一样，中文字体下省略号会被挤出可用宽度。
- **主屏的 App 计数不再每帧建两个列表。** 从前为了拿一个整数要先造一个列表再拷一份，而这条路一帧走四五次。
- 删掉了 1.3.10 加的调试用占位 App 和 `/mcphone debugapps` 命令 —— 那是为了测分页造的脚手架，测完了不该留在正式版里被误触。
- **时钟的算术、天气的判定、问候语的挑选，各自摆在一个不 import 任何 Minecraft 类型的类里**，能用 `javac` 单独编出来跑断言。这三件事有个共同点：**错了不会崩**。时间换算差 6 小时、沙漠里说"下雨"、凌晨三点说"下午好"——全都编得过、跑得起来，只有恰好在那个时刻有人在看才发现得了。靠试玩根本试不出来（真跑一趟沙漠雪山下界还得等到在下雨，半小时起步，未必撞得上雷暴）。
- **六处拿"底色"当字色用**：翻不动的翻页箭头用的是「点不动的按钮那块底」，「已装」两个字用的是「鼠标悬在按钮上时的底」。名不副实之外，它们也不会跟着字体颜色走。各自改成语义对得上的角色。
- 附属模组的页面**自动跟随玩家选的字体颜色**，附属那边一行代码都不用改 —— `PhoneStyle` 当初做成接口而不是一堆常量，为的就是这一天，只是它一直没被自家用上。
