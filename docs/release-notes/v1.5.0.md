# MCphone v1.5.0

三件大的：**聊天 App 改名「美西螈」并加了传送**、**音乐 App 整个重写**、**服主第一次有了自己的配置文件**。

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装
**可选：** Curios —— 装了多一个手机槽
**可选：** Waystones（传送石碑）—— 装了多一个「传送石」App
**可选：** MCEF —— 装了多一个「浏览器」App
**可选：** Integrated Dynamics —— 装了**不**多任何东西，只让崩溃报告指认对人

**从 1.4.2 升级：** 直接替换 jar，**服务端也要换**。存档、好友关系、聊天记录、购买记录、App 安装状态、主屏图标位置全部原样保留 —— 聊天记录的存储格式这一版换了实现但**字节一模一样**，退回旧版本也照读（这一条有 8 万项断言在 `docs/ConversationKeyTest.java` 里钉着）。

服务端会多出一个 `serverconfig/mcphone-server.toml`，见下面「服主的开关」。

---

## 🦎 聊天 App 现在叫「美西螈」

名字和图标都换了。内部标识没动，所以你的好友关系、聊天记录、App 安装状态一条不少。

## ⇢ 传送到好友身边

在线好友那一行的**右下角**多了一个小图标，点它人就过去了，手机同时自动关掉。

落点与原版 `/tp 玩家 玩家` 完全一致 —— 落在他站的坐标上、朝向也和他一样。**跨维度也传**，他在下界你在主世界照样过去。

不需要对方点头：好友本来就要双方同意才加得上，能加上就当作接受了这件事。但**对方会知道** —— 两头各响一次末影人传送声，他的动作栏上还会写明是谁来了。告知不是许可，只是别让人凭空吓一跳。

传送不要钱、没有冷却，也不消耗任何东西。离线的好友没有这个图标。

## ⚙️ 服主的开关（新增配置文件）

`serverconfig/mcphone-server.toml`，眼下只有一项：

```toml
[gameplay]
    allowFriendTeleport = true
```

关掉之后那个图标不再显示，服务端也会拒绝传送请求。**默认开着**，不配置就和上面写的一样。好友关系与聊天不受影响。

用服务端配置而不是客户端配置，是因为后者在每个玩家自己电脑上 —— 用它管"能不能传送"等于把规则交给被管的人。

## 🎵 音乐 App 整个重写

旧的那个只能"点一下响、再点一下停"，而且**列表根本翻不动**（滚轮没接上），19 首唱片一屏之外的全都够不着。

现在：

| | |
|---|---|
| **播放控制** | 播放 / 暂停 / 继续、上一首 / 下一首、进度条、音量（停在播放条上滚滚轮） |
| **循环模式** | 列表循环 / 单曲循环 / 随机 |
| **支持格式** | OGG / OGA、**MP3 / MP2 / MP1**、WAV / AIFF / AU |
| **曲库** | `config/mcphone/music/` 下你自己的音乐 ＋ 游戏里全部唱片（含模组加的） |
| **热重扫** | 往文件夹里丢首歌，进 App 就在，不用重启游戏 |

关掉手机音乐**继续放**，退出世界才停。循环模式和音量记进配置，下次进游戏还是上次那个。

### 🔊 唱片仓：周围的人也听得见

音乐页顶上多了一条唱片仓。**手持唱片点一下放进去**，再点播放 —— 服务端会在你身上播这张唱片，**附近所有人都听得见，声音跟着你走**，就像扛着一台唱片机。放完自动停，`⏏` 把唱片还给你。

外放只有播和停，没有暂停：原版音效系统里没有"从中间接着放"这回事。

**本地的 mp3 不能外放** —— 服务端没法把你硬盘上那个文件发给别人，别人电脑上也没有它。曲库那一列是"耳机"（只有自己听得见，但能暂停、有进度），唱片仓是"外放"。两条路可以同时响。

MP3 解码用的是打包进来的 [JavaMP3](https://github.com/delthas/JavaMP3)（MIT），许可证全文在 jar 里的 `THIRD-PARTY.txt`。

## 🖼 壁纸不用重启游戏了

往 `config/mcphone/wallpapers/` 里拷张图，直接进「更换壁纸」就能看见。以前要重启游戏才认 —— 而"拷张图然后马上想换上"恰恰是这个功能唯一的用法。

## 🐛 这一版修掉的

**会掉线的两处**

- 点进某人会话的同一瞬间他发来消息，有几率让**那名玩家掉线**（消息列表以"活的视图"进了网络包，编码在另一条线程上，撞上就是 ConcurrentModificationException）
- 玩家名超过 16 个字符时**编码阶段抛异常打断连接**。原版用户名到不了 17，但 Geyser/Floodgate 的基岩玩家名带前缀就会

**点错人**

- 好友列表与「加联系人」列表每 3 秒被服务端整份换掉，而点击用的是上一帧算出的下标。中间插进一次替换就会点到另一个人 —— 而那两列里有传送、解除好友、同意好友申请三个不可撤销的动作。现在记的是"谁"，不是"第几行"

**文字画出框**

- 主屏与商店里图标下面的 App 名会压到左右邻居身上（英文名尤其）
- 「关于」页里「Waystones（传送石碑）」和右边的「已装」叠在一起
- 会话输入框打长消息时，末尾那个光标戳出输入栏

**性能**

- 会话列表每 3 秒刷新一次，每个好友要构造两次 73 个字符的会话键。100 个好友、20 人在线，约合每秒 2700 次 `UUID.toString()`，全是纯垃圾。换成记录之后哈希不再分配任何内存，两次查表也并成了一次

**音乐的旧毛病**（除列表翻不动外）

- 换一首歌不停上一首，两首叠着响，旧的再也停不掉
- 停止会把附近唱片机正在放的音乐一起掐掉
- 音量完全绕开游戏的音量滑块，游戏静音了它照响
- 播放状态在音频线程与渲染线程之间裸奔，▶ 一直亮着不复位
- 三句写死的中文，英文玩家在这一页看到中文

## 🧹 顺带清理

- 对好友动手前的两道门（手机在身上、确实是好友）收进一处 —— 它们是安全边界不是风格，漏一处就是个没有任何症状的漏洞
- 操作结果自己说得出该显示哪句话，网络层不再攒一堆文案
