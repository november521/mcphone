# MCphone v1.0.1

新增**便携末影箱** —— 掏出手机就能开自己的末影箱。

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装

---

## 📦 便携末影箱

主屏新增「末影箱」App，点开即可存取。

- **就是原版那个末影箱**：不另存一份数据，与方块末影箱、跨维度完全互通。在手机里放进去的东西，回头用方块末影箱一样拿得到。
- **末影箱与背包同屏**：27 格在上、背包在下，可以直接拖拽，不用来回切换。拖拽分配、shift 点击、双击整理这些原版操作全部照常。
- **手机不在身上就自动关闭**：这才配叫"便携"。把手机拿到光标上挪位置不会误关。
- **服务端校验**：开箱请求会检查玩家手上确实拿着手机，改客户端也没法凭空开箱。

物品搬运走的是原版容器系统，服务端权威，不存在刷物品的路径。

---

## 🔧 其他

- 给附属模组作者：手机机身的绘制（外壳、壁纸、状态栏、导航栏）抽成了可复用的 `PhoneChassis`，并支持自定义尺寸，做带格子的界面时不必再受竖屏机身宽度限制。
