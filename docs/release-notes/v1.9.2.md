**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装
**可选：** Curios —— 装了多一个手机槽
**可选：** Waystones（传送石碑）—— 装了多一个「传送石」App
**可选：** MCEF —— 装了多一个「浏览器」App
**可选：** NetMusic（网络音乐机）—— 装了唱片仓还收它刻的 CD
**可选：** Patchouli（教程手册）—— 装了多一个「阅读」App
**可选：** FTB Quests —— 装了多一个「任务书」App
**可选：** Integrated Dynamics —— 装了**不**多任何东西，只让崩溃报告指认对人

**从 1.9.x 升级：** 直接替换 jar。这一版改的全在客户端，**没动网络包，也没动任何存储格式**——存档、好友、聊天记录（含图片）、购买记录、App 安装状态、主屏图标位置、手机里的唱片全部原样保留。

## ⌨ 每个 App 一个快捷键

「设置 → App 管理器 → 点开某个 App」里多了一行**快捷键**：点一下，然后按你想用的那个键——以后在世界里按它就直接开机并进这个 App，不必再「开机 → 找图标 → 点开」。

**默认未指定**，每个 App 各绑各的。绑过的键会写在管理器列表那一行的右边，一眼扫得完谁绑了什么。

**键盘、鼠标键都行**，包括鼠标侧键（4/5）、中键、右键——和原版「按键设置」里能绑的范围一样。**左键除外**，它在等键时是"算了"：左键是你在手机里点东西的那只手，绑上去的话每挖一次方块都会开一次手机。绑在鼠标键上的 App 打开时**不会顺带挥手或用一次物品**。

**支持组合键**：按住 Ctrl / Shift / Alt 再按主键，可以叠（Ctrl+Shift+K），鼠标键同样可以。触发要求**完全一致**：绑了 Ctrl+K，光按 K 不开，按 Ctrl+Shift+K 也不开——否则两个 App 分别绑这两个组合时，后者会连着前者一起响。Mac 上的 Command 就是这里的 Ctrl。

**ESC 是清除**，与原版「按键设置」里的意思一致，不用学第二套。

**撞了车不拦你，但会先说一声。** 一个组合已经被别的 App、或者被原版／别的模组的键位占着时，那一行会变成「再按一次强制」并写出被谁占的；再按同一个组合就照绑，之后那一行一直带个 ⚠。要说这一声是因为这套快捷键**不出现在原版的按键设置界面里**——真让「按 E 同时开背包和手机」默默发生，你日后查不出是谁干的。

顺带一提，加修饰键**并不等于避开冲突**：原版键位判要不要响应时不看你有没有按住修饰键，所以 Ctrl+E 照样连带开背包。真按下去时手机会把那条键位攒的点击倒掉，不至于等你关掉手机再补开一次背包。

绑定是**客户端**设置，存在 `config/mcphone-client.toml` 的 `appHotkeys` 里，跟着这台电脑走，换服务器、换存档都在。手机已经开着时按这些键不会切换 App：那时候你多半正在手机里打字。

**附属模组不用做任何事**，绑定按 App id 走，内建与附属一视同仁。

## 📷 快门闪光可以换成「模糊一下」

「设置 → App 管理器 → 相机」里多一行**快门闪光**，在**白闪**与**模糊**之间点着换，默认还是白闪。

白闪是照相机的老习惯，但夜里或在暗处拍照时它会把整个屏幕顶到全白，眼睛得缓几秒；模糊那一版只是把画面糊一下再收回来，同样交代了"拍下来了"，亮度不变。**两种都不会进照片**——闪光是抓完图之后才开始的。

模糊借的是原版菜单背景那条后处理链，不额外带着色器文件，半径跟着时间收，所以是化开又收回去，不是硬切一块糊画面。**它不受你的「菜单背景模糊度」设置影响**——把那一项调成 0 的人，这里照样看得到模糊。

## 🎨 界面贴图补了十八张

状态栏、主屏拖动时的空槽、两颗页码点、翻页提示条、商店的可点与不可点按钮底、浏览器的面板与工具条、阅读的搜索栏 / 标签 / 收藏与未收藏两颗星，加上聊天的两种气泡、输入栏底、消息通知底与未读角标——这些位以前只有兜底纯色，现在模组自带。资源包放同路径的图仍然照常覆盖。

**气泡这类会被拉伸的底，圆角不再抻变形。** 在 PNG 旁边放一份同名的 `.png.mcmeta`，内容 `{"mcphone_skin": {"border": 3}}`，这张图就改走九宫格：四角按源图上那 3 个像素原样画，只有四条边和中间被拉伸，气泡多宽多高四个角都一样大。`border` 大于源图短边的一半时忽略，退回整张拉伸；不写这份元数据的老资源包什么都不用改。模组自带的两种气泡与输入栏用的就是这份元数据。

**给资源包作者新开了三个位**：`browser/back`、`browser/forward`、`browser/reload`（浏览器工具条上的后退 / 前进 / 刷新，建议 22×18）。模组暂时没有自带图，缺图时照旧画 ◀ ▶ ↻ 三个字符。

换肤文档里也补了一条以前没写清的规矩：**贴图改不了颜色，状态只能靠亮度或透明度**。悬停、点不动这类状态，没有贴图时是换一个颜色画的；一旦这个位上有了贴图，那个颜色就再也看不见。所以模组在有贴图时改用别的表达——导航键与商店按钮悬停是整张提亮，浏览器那三个键点不动时是整张压暗，音乐键与聊天的「+」把高亮块画在贴图底下。画贴图时不必自己去表达这些状态。
