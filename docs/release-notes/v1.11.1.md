# MCphone v1.11.1

本次更新加入方块键切换手机 HUD，并修复与创世神（WorldEdit）同时安装时的 Rhino 引擎冲突。

## 运行环境

- Minecraft 1.20.1：Forge 47.4.0 或更高，Java 17。
- Minecraft 1.21.1：NeoForge 21.1.200 或更高，Java 21。
- Minecraft 1.21.1：Fabric Loader 0.15.0 或更高、Fabric API，Java 21。
- 客户端与服务端均需安装对应加载器的版本。

关闭游戏后替换原来的核心 JAR，同一实例保留一份 MCphone，并保留附属模组。升级前请备份世界。

## 手机 HUD

- 在手机界面点击底部方块键，将当前手机切换为 HUD 浮窗。
- 在 HUD 中唤出鼠标后，再点击方块键可返回普通手机界面。
- 切换时复用当前手机，保留页面、输入草稿及滚动状态。
- 继续支持原有 HUD 快捷键、鼠标交互、拖动与尺寸调整。

## 创世神兼容

- 修复 MCphone 与 WorldEdit 所用 Rhino 引擎的包与模块冲突。
- 开发、测试与发行包统一使用固定版本的内部脚本引擎，补齐对应源码、来源与文件摘要记录。
- 玩家仍只需安装一个 MCphone 核心 JAR，现有脚本格式与网络协议不变。

## 26.1.2 NeoForge 移植进展

已完成源码移植，并修复相机界面错位和 HUD 唤出鼠标时出现整屏菜单模糊背景的问题。此目标仍按仓库声明保留为测试目标，不包含在本次正式发布的三个 JAR 中。
