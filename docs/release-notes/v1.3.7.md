# MCphone v1.3.7

记事本的两个小毛病，一个上手体验的调整，三张新图标。

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装
**可选：** Curios —— 装了多一个手机槽
**可选：** Waystones（传送石碑）—— 装了多一个「传送石」App
**可选：** MCEF —— 装了多一个「浏览器」App

**从 1.3.0 升级：** 直接替换 jar。存档、购买记录、App 安装状态都不受影响。

## 📝 记事本

**滚动条不再伸到手机外面。** 写长笔记时右边那条滚动条会压在机身边框上。原版把滚动条画在输入框的**外侧**，而输入框原来占满了整个内容区，滚动条自然就出界了。现在输入框让出这一条的宽度。

它的粗细我们改不了——那是原版方法体里的字面量，而且那个方法是 `private`。要改只能把整个多行输入框重写一遍，为一条滚动条的粗细不划算。

**「打印」挪到了笔记列表里。** 原来它在编辑页底部，挤在「保存」和「删除」中间。而删除点第一下会变成「再点一次删除」，右对齐往左长出一大截，正好压住打印——112 像素宽的屏幕上重叠 7 像素。

挤只是表象：打印对笔记做的事跟"编辑"本来就无关。现在它在**列表页每条笔记的尾部**，绿色，点一下就印，不用先点进去。

顺带消掉了一个状态：编辑页原来有「新建还没保存过的笔记不能打印」要画成灰的，挪到列表之后这个状态自然不存在了——列表里的每一条本来就都保存过。

编辑页现在只剩保存与删除，一左一右，删除上膛后撞不到任何东西。

## 📱 免费的 App 现在开局就装好

相机与相册明明免费，新玩家第一次打开手机却看不到它们，得先进应用商店点一次「下载」。那一趟没有任何意义——他不需要做决定，也没有别的选项。

现在**免费的 App 首次进世界就在主屏上**。付费的（末影箱、传送石）不变，仍然要先买。

判断拆成了两条：App 自己声明「我想不想默认在主屏」，以及「它是不是付费的」。后者是硬约束，不看谁的意愿——一个 App 声明了价格却忘了关掉预装，玩家就会白得一个本该花钱的东西。

**已有存档不受影响。** 老存档里没装相机的仍然没装，因为那些 App 在目录里出现过，走的是「沿用玩家自己的选择」那条路。我们分不清「他不想要」和「当年根本没给他」，而把玩家主动卸掉的东西塞回主屏，比少装一个更冒犯。

要看到这个变化，开一个新存档。

## 🎨 三张新图标

- 应用商店的**「联动App」入口格**终于有真图标了（三个点），在这之前画的是代码兜底的纯色底加三个小方块
- **设置** App 换了新图标
- **饰品栏槽位**（装了 Curios 才看得见）换了新图标

兜底的画法都还留着：资源包把这些换掉又没给新图时它们接着顶上。「贴图优先、纯色兜底」这条规矩不因为有了真图就废掉。

## 🖌️ 给资源包作者：放图时整条路径要么全新、要么全老

1.2.8 起贴图按功能分了目录，老路径仍然认。但两套规则**不能各取一半**：

| | 目录 | 文件名 |
|---|---|---|
| 现在 | `textures/app/` | App 短名，如 `settings.png` |
| 老的（仍然认） | `textures/gui/` | `app_icon_settings.png` |

写成 `textures/app/app_icon_settings.png` 这样混着来，两条查找路径都对不上——**不会报错，只是那张图永远不被读到**，主屏上还是旧图标。这类「画了等于没画」最难自查，因为一切看起来都正常。

另外文件名只能用 `a-z 0-9 _ . - /`。中文、空格、大写都会让 Minecraft 判为非法资源路径直接跳过，而报错信息里只提路径不提是哪个模组的。

完整对照表见 README 的「换肤」一节。
