# MCphone v1.1.6

手机里多了一个「传送石」App —— 装了传送石碑（Waystones）就会出现。

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装
**可选：** Curios —— 装了多一个手机槽
**可选：** Waystones（传送石碑）—— 装了多一个「传送石」App

**从 1.1.0 升级：** 直接替换 jar，存档会自动迁移，不需要重开世界。

---

## 🪄 传送石

主屏上的第九个 App。点开就是传送石碑**自己的**选点界面——和你手持传送石右键看到的那一个完全一样。

- **列表、排序、搜索、分组、传送特效都是它的**，我们一样都没重画。它更新界面，手机里跟着更新。
- **代价按传送石算，不是按背包按钮。** 服主怎么配传送石，这个 App 就怎么走：他设成无冷却，手机也无冷却；他改了经验消耗，手机跟着改。不需要另外学一套 MCphone 的配置。
- **不扣耐久** —— 手机里本来就没有那块石头。说明白：在"无冷却 + 扣耐久"这类配置下，这个 App 比真传送石更耐用，真石头 128 次会碎，手机不会。
- **没装 Waystones 的话，这个 App 压根不存在** —— 不是灰着点不动，是主屏和应用商店里都看不到它。
- 万一服务端版本对不上导致开不出来，屏幕下方会直接告诉你原因，不会让你对着没反应的图标反复点。

## 🧩 给附属模组作者

**新增 `IPhoneApp.isAvailable()`**

你的 App 依赖另一个可选模组时，覆盖它即可：

```java
@Override
public boolean isAvailable() {
    return ModList.get().isLoaded("someothermod");
}
```

返回 false 就不进目录 —— 主屏与应用商店里都不会出现。应用商店里躺着一个点了会报错的东西，比它压根不存在更糟。

默认返回 true，现有 App 一行都不用改。

判断为什么要放在接口里、而不是让你自己挑时机调 `register()`：App 的登记顺序、预装判定、与玩家历史选择的对账都发生在目录构建的那一瞬间。绕过 SPI 自己登记，要么排在目录最前面打乱主屏顺序，要么错过对账窗口让 `isPreinstalled()` 失效。
