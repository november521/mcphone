# MCphone v1.0.20

手机能打字了 —— 加好友、聊天、离线留言，一部手机全办完。

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装

---

## 💬 聊天

主屏的「消息」与「联系人」两个占位合并成了一个**聊天 App** —— 在任何一部真手机上，这两者本来就是同一个东西的两半，分开占两格既浪费又反直觉。

### 好友是双向的

- **申请 → 同意 / 拒绝**：加好友要对方点头。单向添加是设计错误——你加了对方，对方那边什么都不会发生。
- **从在线玩家里点选**：不用打名字，点一下就发出申请，也不会打错字。
- **两个人同时点「添加」直接成为好友**：谁也加不上对方是很蠢的体验。
- **解除好友是双向的**：没有"我删了你但你还留着我"这种半吊子状态。聊天记录不删——那是双方共有的，单方面抹掉等于替对方做决定。重新加回来，历史就回来了。

### 会话

- **会话列表**：未读数、在线状态、最后一条消息预览、时间。有消息的排在前面，没聊过的沉底。
- **会话界面**：自己的靠右、对方的靠左，长消息自动折行，隔了一段时间会插一行时间戳。
- **消息存世界存档**：对方不在线也能发，他下次上线就能看到。
- **聊天限定在好友之间**：陌生人根本发不进来。

### 上限

好友 100 人，每人待处理申请 50 条，每对会话保留最近 100 条消息，单条 256 字。申请上限是防刷屏用的——没有它，一个人可以给同一个受害者制造无数条申请，把对方的申请列表和存档一起撑爆。

## ⌨️ 关于中文输入

手机里的输入框（聊天、设备命名）用的就是原版按 **T** 那个聊天框的同一个控件，**能不能打中文与原版完全一致**。

但要提醒一句：Minecraft 不会把输入法候选窗定位到光标处（GLFW 缺少相应接口，原版聊天框也一样），打拼音时基本看不见候选列表，等于盲打。想稳妥就用 **Ctrl+V** 粘贴。

## 🎨 换肤

新增 `PhoneSkin`：手机外壳、状态栏、导航栏、导航键图标、聊天气泡、输入栏，每一处都是**贴图优先、纯色兜底**——放了贴图就用贴图，没放就用内置配色，不会出现缺图变紫黑块的情况。

资源包把 PNG 放进 `assets/mcphone/textures/gui/` 即可，文件名见各元素说明。气泡与输入栏会被整张拉伸，做成纯色或纵向渐变最稳妥。
