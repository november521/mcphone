# MCphone v1.2.5

手机现在会告诉你，它还能多出什么。

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装
**可选：** Curios —— 装了多一个手机槽
**可选：** Waystones（传送石碑）—— 装了多一个「传送石」App
**可选：** MCEF —— 装了多一个「浏览器」App

**从 1.2.0 升级：** 直接替换 jar。存档、购买记录、App 安装状态都不受影响。

---

## 🔗 应用商店多了一页「联动 App」

有些 App 靠别的模组撑着：传送石要 Waystones，浏览器要 MCEF。前置没装时，它们不会出现在主屏和商店的普通列表里——商店里躺着一个点了必然报错的东西，比它不存在更糟。

**但那样你也就无从知道自己缺了什么。**

所以商店的第一格现在是「联动App」。点进去一行一个列着：图标、名字、需要哪个模组、已装还是未装。前置没齐的整行压暗，看得见、点不动。

前置齐了的排在前面，没齐的排在后面——先看到「我已经有的」，再看到「还能有的」，不用从一堆灰条里找哪个是亮的。

这一页的行本身刻意不可点：能用的去商店正常下载，用不了的点了也没有任何能做的事。弹一句「请去装 MCEF」，不比那行已经写着的「需要 MCEF · 未装」多说什么。

## ℹ️ 关于页漏了 MCEF，修了

**这是 v1.2.0 的一个疏漏。** 「设置 → 关于」里那份联动模组列表原来是手写的两行，Curios 和 Waystones。v1.2.0 加了浏览器 App，需要 MCEF，却没人记得回来加第三行。

于是没装 MCEF 的玩家在关于页上看不到任何线索——而这一页存在的全部理由，就是回答「我怎么没有这个 App」。

现在这份列表不再手写，而是从各个 App 声明的前置自动汇总。以后任何 App（包括附属模组的）声明了新的前置，这一页自动就有，漏不掉。

标题也从「兼容」改成「联动模组」：「兼容」听着像「能不能一起装」，而这里说的是「装了会多出什么」。

Curios 仍然单独列一行——它是能力型联动，装了手机能挂腰上，不对应任何一个 App，汇总不出来。

## 🎨 给资源包作者

新增一张贴图，仍然是贴图优先、纯色兜底：

| 元素 | 路径 | 建议尺寸 | 没放时 |
|---|---|---|---|
| 「联动App」入口格图标 | `assets/mcphone/textures/gui/store_companion.png` | 20×20 | 纯色底加三个小方块 |

兜底刻意不画字符。好看的符号（❖ ⚭ 之类）在部分字体下会掉成方框，而这是玩家进商店第一眼看到的格子——这跟「已装/未装」用文字而不用 ✓ ✗ 是同一个理由。

另外订正了一处旧注释：`browser_bar.png` 的建议尺寸是 **320×22**，不是原来写的 320×18。工具条高度在 v1.2.0 里就调到 22 了，注释没跟上。贴图是整张拉伸的，照 18 画不会报错，但带圆角或纵向渐变的图会被拉长一截。

## 🧩 给附属模组作者

**新增 `IPhoneApp.requiredMods()`** —— 声明你的 App 需要哪些外部模组：

```java
@Override
public List<RequiredMod> requiredMods() {
    return List.of(new RequiredMod("someothermod", "Some Other Mod（显示名）"));
}
```

声明一次，三件事自动发生：

1. 对方没装时你的 App 不进目录，主屏与商店的普通列表里都不出现
2. 它出现在商店的「联动App」页，缺哪个模组写得明明白白
3. 手机里「设置 → 关于」的联动模组列表自动带上它

**显示名要自己写死，别在运行时从 `ModList` 查。** 要显示它的那一刻，那个模组正好没装，`ModList` 里什么都没有，只剩一个 modid——让玩家看到「需要 someothermod」不算说明白。

**`isAvailable()` 的默认实现改成了按 `requiredMods()` 回答**，所以声明前置就够了，不必再覆盖它。已经覆盖了 `isAvailable()` 的实现照常工作，这是纯增量、不破坏兼容。只是覆盖了它却不声明前置的话，「联动App」页会与真实可用性对不上。

判断条件确实说不清时（比如还要看对方的版本）再覆盖 `isAvailable()`。

**`RequiredMod` 里刻意没有下载链接字段。** 想过让玩家点了直接用手机里的浏览器打开，但那是个死结：浏览器本身就是联动 App，没装 MCEF 时它不可用——而那正是最需要链接的时候。一个只在你已经不需要它时才能用的按钮，不如不做。
