# MCphone v1.4.2

一个小改动，但你每次收手机都会用到：**按 `Esc` 直接关机，不管开到第几层。**

**运行环境：** Minecraft 1.21.1 · NeoForge 21.1.200 或更高 · 客户端与服务端都需安装
**可选：** Curios —— 装了多一个手机槽
**可选：** Waystones（传送石碑）—— 装了多一个「传送石」App
**可选：** MCEF —— 装了多一个「浏览器」App
**可选：** Integrated Dynamics —— 装了**不**多任何东西，只让崩溃报告指认对人

**从 1.4.0 升级：** 直接替换 jar。存档、好友关系、聊天记录、购买记录、App 安装状态、主屏图标的位置，全部原样保留。

## ⎋ `Esc` 一键关机

原来 `Esc` 是「退回上一层」，只有已经站在主屏上时按它才关机。于是从记事本的编辑页回到游戏要按三下：编辑页 → 笔记列表 → 主屏 → 关。

现在按一下就走。

改的理由不是少按两下，而是 `Esc` 在这个游戏里从来只有一个意思：**把眼前这个界面收掉。** 背包、合成台、村民交易、原版任何一个界面，按 `Esc` 都是回到游戏，没有一处是往回走一格。手机借了这个键，就该守它原本的含义——玩家按下它是想「不玩了」，不是想「上一页」。

浏览器那边（v1.2.0 起）本来就是 `Esc` 直接关，两个界面现在一致了。

**退回上一层没有取消**，走屏幕底部导航栏的 `◀`，规则一个字没改：相册的单张查看退回缩略图、「关于」退回设置、App 详情退回商店，都和以前一样。

| 怎么按 | 结果 |
|---|---|
| `Esc` | 不看层级，直接关机 |
| 导航栏 `◀` | 退回上一层；已经在主屏上时不做事 |
| 背包键（默认 `E`） | 不在主屏 → 回主屏；在主屏 → 关机 |
| 点手机外面 | 关机 |
| `H` | 开机，手机在背包或饰品槽里也行 |

有一处没变，说清楚免得误会：记事本编辑页、设备命名、聊天输入框，按 `Esc` 走人**不会自动保存**——这三处原先按 `Esc` 也是直接走、也不保存，只是当时走到上一层就停下了。要留住内容还是点「保存」。

## 🌐 壁纸页不再对英文玩家说中文

「设置 → 更换壁纸」这一页有六句话是写死的中文：标题、「恢复默认背景」、以及一张壁纸都没有时那四行提示。语言切成 English 的玩家在整个手机里只有这一页看到中文。

翻译文件里这六条早就写好了，从来没人用。接上了。

这是最后一处——现在手机里没有第二个不跟随语言的界面。

## 🧩 给附属模组作者

**`Esc` 不再触发 `IPhonePage.onBack()`。**

`onBack()` 现在只由导航栏的 `◀` 触发。如果你把「退出前提醒保存」「页面内还有一层要退」这类逻辑挂在 `onBack()` 上，玩家按 `Esc` 时它**不会响**。

要在页面被收走之前做事，挂 `onClose()`：

```java
@Override
public void onClose() {
    saveDraft();   // Esc、◀、关机、断线，四条路都会走到这里
}
```

`onClose()` 那句「一定会被调用」仍然成立，`Esc` 关机走的是 `removed()`，里面会把当前附属页面收掉。

`IPhonePage` 的三处文档已经改过来了。`keyPressed()` 依旧收不到 `Esc`——这个键不开放给页面拦截，「玩家按了退出却什么都没发生」是最糟的一种失败。
