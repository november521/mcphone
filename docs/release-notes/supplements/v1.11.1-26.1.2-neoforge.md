# MCphone v1.11.1 — Minecraft 26.1.2 NeoForge

26.1.2 NeoForge 已由用户完成游戏测试，本包正式加入 MCphone 1.11.1 发布。

## 运行环境

- Minecraft 26.1.2，NeoForge 26.1.2.100 或更高（同一 Minecraft 26.1.2 系列），Java 25。
- 客户端与服务端均需安装此目标对应的 MCphone 核心 JAR。
- 测试基准整合包为 ATM11 0.11.1-beta；其他整合包及全部可选联动不据此承诺兼容。

## 更新内容

- 完成 Minecraft 26.1.2 NeoForge API 与官方 Mixin 布局移植。
- 修复相机准星、取景框及闪白效果错位。
- 修复与创世神（WorldEdit）同时安装时的 Rhino 引擎冲突，统一使用固定内部依赖。
- 点击底部方块键可在普通手机界面与 HUD 之间切换，保留页面、草稿及滚动状态。
- 修复 HUD 唤出鼠标时出现整屏菜单模糊背景的问题。

关闭游戏后替换旧的 MCphone 核心 JAR，同一实例保留一份核心模组，并保留附属模组。升级前请备份世界。

本次为已有版本补充目标包：从原 `v1.11.1` 标签构建，不变更标签、版本号和此前已发布的三个 JAR。最初发布说明将此目标标为测试目标；本记录补充其验收与正式发布状态。
