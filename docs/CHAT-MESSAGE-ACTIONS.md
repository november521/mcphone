# 消息右键菜单与个人删除

分支：`codex/chat-message-actions`。范围仅为复制文字和个人删除；转发、引用、收藏、多选等未实现，也不显示占位菜单项。

## 交互

在文字气泡或图片消息上按鼠标右键，显示紧凑竖排菜单。面板沿用粉色半透明圆角，删除项使用危险操作颜色；菜单限制在手机内容区，靠右、靠下时向内移动。

文字消息显示「复制消息」「删除消息」。当前消息有非空选区时第一项改为「复制选中文字」；复制保留原文，不把自动折行转换成换行。图片消息仅显示删除，不把图片 ID 或提示文字写入剪贴板。删除始终作用于完整消息。

点击菜单外、滚轮或 ESC 只关闭菜单；这一事件不触发下层导航、输入、缩放或关机。菜单打开时阻断字符、Enter 和拖动，避免修改或发送草稿。再次右键另一条消息可更换菜单目标。目标被淘汰或删除时菜单关闭；历史重同步生成新对象时按稳定 ID 保留目标与选区。

删除只影响当前连接玩家的个人记录，对方仍能查看原消息及图片。服务端校验手机、好友和会话 ID，发送个人历史与摘要后再确认结果；客户端不做乐观删除。等待确认期间禁用再次删除，但仍可复制。6 秒未收到确认时清理票据并提示重新打开会话确认结果；超时不等于服务端未执行。关闭、切换会话、退出世界都清理票据，迟到确认不能影响下一次操作。

## 文件边界

路径前缀为 `shared/src/main/java/com/november/mcphone/feature/chat/`。

```text
client/messageaction/
  ChatMessageActions.java       唯一公开入口：页面注入绘制、复制、删除、取消和提示回调
  ChatContextMenu.java          展示、标签、悬停和命中，交出操作意图
  ChatContextMenuLayout.java    纯几何：放置、边界和行命中
  ChatMessageTarget.java        菜单打开时捕获的不可变目标与复制来源
  ChatMessageAction.java        当前操作集合

ChatDeletionResult.java         共享结果值，显式线格式编号
ChatMessageDeletionService.java 服务端删除业务与权限入口，不发送网络包
ChatDeletionData.java           世界 SavedData 持久化与损坏数据保护
ChatMessageVisibility.java      包内纯个人可见性规则与标记清理
ChatMessageIdentity.java        包内旧消息 ID 迁移规则
net/ChatClientCache.java        当前会话快照及纯数据确认收件箱
```

`ChatConversation` 协调消息区、输入框、查看器与菜单，不绘制菜单内部。`ChatMessagePane` 只提供裁剪后的消息命中、选区和绘制。模块通过回调访问系统剪贴板和发请求，不依赖页面、网络实现或 SavedData。

`DeleteChatMessagePacket` 与 `ChatMessageDeleteResultPacket` 位于 `layers/version/1.20.5+/`；Forge 1.20.1 的 FriendlyByteBuf 版本位于平台目录。三个 `ChatNetworking` 仅承担注册、主线程业务调用、限流、权威快照及确认发送。

## 数据与兼容

消息增加稳定 UUID，新消息由服务端生成；三参数构造入口保留。旧文本格式和已有图片格式仍可加载；缺 ID 或重复 ID 的旧记录按会话、原始位置、发送者、时间及正文确定性迁移，迁移后安排保存。同一份旧存档重复装载得到相同 ID，避免聊天文件与删除文件保存顺序不同导致标记失配。相同正文、相同时间的重复消息仍能独立删除。

个人删除标记保存在主世界 `data/mcphone_chat_deletions.dat`，按「本人 UUID + 会话 + 消息 UUID」隔离。历史、会话最后一条和未读数从可见消息计算；公开 PhoneChat.conversation API 同样使用本人可见记录。共享消息仍按原有 100 条上限保留，图片回收仍根据原始记录引用；个人删除不删除图片文件。消息被容量淘汰时，两方对应标记一起清理。

删除标记结构损坏时返回保留原文的锁定实例，暂时停止历史读取和新删除，日志提示服主恢复备份；不能抛给原版 SavedData 后被重建为空实例，也不能把未知结果当成功。持久化使用原版世界保存生命周期，不承诺在进程崩溃前尚未保存的操作落盘。

聊天线格式有变更，客户端和服务端必须同步更新。Forge 通道版本从 6 到 7，NeoForge 注册版本从 3 到 4。现代历史和推送通道改为 `sync_messages_v2`、`new_chat_message_v2`；Fabric 在两端进入游戏时检测已安装 MCphone 的旧对端并提示版本不兼容。未安装 MCphone 的连接行为沿用既有逻辑。

旧版本能忽略文本的新增 ID 字段，但旧版本重新保存可能丢弃 ID，也不会执行个人可见性过滤。因此启用个人删除后的聊天数据不支持降级语义保证，应恢复升级前世界备份再降级。

## 验证

专项测试覆盖实际 NBT 重载与迁移、重复记录、双方隔离、摘要/未读、图片引用保留、损坏数据保护、菜单几何、复制原文、确认票据、超时/生命周期和两种线格式。接缝清单与孪生基线由 Gradle 任务生成，差异新增部分来自删除协议及 Fabric 的兼容检测。

游戏验收仍需进行，编译与无窗口测试不能确认面板观感、实际鼠标坐标及完整联网流程。测试包、各平台完整构建结果和 SHA256 见本地预览目录的 `validation.json`。

1. 文字气泡右键复制整条；拖选局部后右键复制选区；中英文和多行原文复制正确。
2. 右键自己和对方的消息删除，另一端仍显示；关闭重开会话、重进世界和重启服务端后删除仍生效。
3. 两条相同正文分别删除；同一张图片发多次只删目标记录，另一端与另一条图片仍可查看/保存。
4. 删除最后一条后预览回退；全部删除后预览为空，没有残留未读角标。
5. 靠手机四边的菜单、不同手机/GUI 缩放、各字体预设下的命中、透明度、圆角与文字可读性。
6. 菜单打开后点外部、导航、输入框，按 ESC、Enter、字符、滚轮，确认只关闭或阻断，草稿不发送。
7. 删除待确认时切换会话、关闭手机、断线、重连；旧票据和旧菜单不残留。
8. 输入框选字与发送、附件菜单、图片上传/放大/保存以及离线头像不回归。
