# MC 百科搜索与原文跳转

需要本轮支持 `@click="openUrl(url)"` 的验收 JAR。将 `mcmod-search.vue` 放入游戏目录 `mcphone/apps/`，从 AppStore 的本地来源安装“MC百科搜索”。若已经安装验证版，替换原 `.vue` 文件后重新进入商店更新，同一个 App id 不要保留两份来源文件。

1. 输入“机械动力”“AE2”或“JEI”，点击搜索。两次发起至少间隔 10 秒。
2. 查看返回的最多 5 条模组标题、短摘要及原文地址。网站排序不保证主模组在第一条。
3. 点击某条结果的“查看原文”，系统默认浏览器应打开该条 MC 百科原文地址。
4. 返回游戏，搜索结果和输入应保留；继续测试另一条，确认地址对应当前条目。
5. 手机和平板分别确认输入、搜索、结果滚动和“查看原文”按钮可用。

本步只查询模组搜索页。网页详情交给系统浏览器，不依赖 MCEF；搜索响应仍遵守 64 KiB 接收上限。网站不可达、返回过大或结构变化时显示失败提示。摘要仅进行基础 HTML 清理，可能保留百科标记和少量实体编码。
