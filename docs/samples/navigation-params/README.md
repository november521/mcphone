# 便签导航演示

需要支持页面导航传参的开发构建；`1.12.0` 正式版尚无此能力。这个示例只有客户端页面，不包含服务端脚本。

目录结构：

```text
manifest.json
app.vue
pages/detail.vue
assets/icon.png
```

将上述四个文件按原路径打成 ZIP，根目录应直接是 `manifest.json` 和 `app.vue`，放入游戏的 `mcphone/apps/` 后从应用商店安装“便签导航演示”。验收交付目录提供可直接安装的 `navigation-params.zip`。

列表页的每行通过 `nav('detail', { id: note.id, title: note.title })` 传参；详情页在无参 `onInit()` 内读取只读 `ctx.params`。详情草稿上限为 1024 个 UTF-16 单元，使用现有本地存储按便签编号分别保存。

建议验收：

1. 在列表输入框写入草稿，打开“便签 1”，标题与正文应对应编号 1。
2. 写入多段正文并保存，再改成另一段未保存内容。
3. 点击“下一条”，同一个详情页应显示编号 2 自己的内容，不沿用编号 1 的草稿。
4. 点击返回，应恢复编号 1 的未保存内容；再次返回列表，列表草稿与打开次数仍保留。
5. 关闭 App 后重开，再打开编号 1，应从本机记录恢复最后保存的正文。不同编号分别保存。

每个页名只缓存最近的一组参数，返回栈另保留原页；因此跨不同编号任意跳转时，应显式保存需要长期保留的正文。图标复用本仓库的笔记图标。
