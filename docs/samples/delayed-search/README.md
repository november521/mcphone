# 搜索防抖演示

需要本轮支持 `ctx.timer.after` / `ctx.timer.cancel` 的测试 JAR。将 delayed-search.zip 放入游戏 mcphone/apps/，从 AppStore 安装“搜索防抖演示”。此示例使用独立 App id，不覆盖便签数据。

1. 连续输入“便签 2”，停下约 300 毫秒后才应用筛选，“已查询”只增加一次。间隔超过 300 毫秒的每段输入分别计数。
2. 清空输入，停下后恢复全部三条。结果会在页面 tick 执行，低帧率或暂停时可以晚于设定时间。
3. 输入一个筛选条件，点击“安排 3 秒后查询”，随即点击“取消等待”，等 3 秒，查询次数应不增加，输入草稿保留。
4. 再次安排 3 秒任务，立即点“切页测试”，等几秒再返回，查询次数不增加，旧任务不恢复。修改输入后可以安排新任务。
5. 安排任务后关闭 App，等几秒重新打开，查询次数从 0 开始，旧任务不执行。
6. 手机和平板均检查输入框、取消、切页、3 秒按钮和结果列表。

演示只在本地筛选三条便签，不依赖网络。真实 App 可以在同样的延迟回调中调用已有 ctx.http.request。

ZIP 根目录应为 manifest.json、app.vue、pages/away.vue、assets/icon.png；README 不包含在安装包内。
