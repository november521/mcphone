FlatLaf
================================================================

用途     文件选择器（壁纸「选择图片」）的界面外观。
         不装它也能用，只是对话框退回 Swing 默认的灰色 Metal 风格。
Used for the look and feel of the file chooser (Wallpaper -> Pick image).
Without it the dialog still works, it just falls back to Swing's Metal look.

坐标     com.formdev:flatlaf:3.7.2
主页     https://github.com/JFormDesigner/FlatLaf
位置     META-INF/jars/flatlaf-3.7.2.jar（只有 Fabric 目标打包它；
         另外两个目标的选择器用系统外观，见下方说明）

Pixelarticons - battery-full / cellular-signal-3 / chat UI
================================================================

用途     状态栏固定满电电池、满格信号，以及聊天、联系人、发现、个人页、搜索图标（纯白透明 PNG）
Used for the status bar and chat UI icons (white transparent PNGs).

主页     https://github.com/halfmage/pixelarticons
原图     https://pixelarticons.com/svg/battery-full.svg
         https://pixelarticons.com/svg/cellular-signal-3.svg
位置     assets/mcphone/textures/phone/battery_full.png
         assets/mcphone/textures/phone/signal_full.png
         assets/mcphone/textures/chat/ui/{message,contact,compass,user,search}.png
原稿     聊天图标原始 SVG 位于 docs/assets/chat-ui/，来源为 Pixelarticons 同名图标。
转换     用户提供的 24x24 纯白透明 PNG，在本模组中原样打包。
         User-provided 24x24 white transparent PNGs, bundled without further changes.
